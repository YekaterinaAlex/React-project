# React Pokémon App

React application for browsing Pokémon with routing, state management, theme switching, selected items, CSV export, and RTK Query API caching.

## Features

- Pokémon list with server-side pagination
- Pokémon details panel
- Search by Pokémon name
- Selected items state with Redux Toolkit
- CSV download for selected Pokémon
- Light/dark theme using Context API and styled-components
- API fetching and caching with RTK Query
- Manual refresh for list and details data
- Loading and error states
- Unit and integration tests with Vitest and React Testing Library

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Redux Toolkit
- RTK Query
- styled-components
- Vitest
- React Testing Library
